R2K Tool Library

Place downloaded tools in the matching folder:

01_Boot_Recovery_ISOs      Boot ISOs and boot media helpers.
02_Diagnostics_Hardware    Drive health, sensors, CPU/GPU, RAM support tools.
03_Backup_Data_Recovery    Imaging, cloning, file recovery, transfer tools.
04_Malware_Cleanup         Malware, PUP, adware, and offline scanners.
05_Windows_Repair          Sysinternals, DISM/SFC helpers, update repair.
06_Account_Recovery        Legitimate recovery notes and support links only.
07_Drivers_Firmware        OEM updaters, SDIO, driver packs.
08_Network                 Network scanners, capture tools, profile tools.
09_Cleanup_TuneUp          Disk space, uninstallers, cleanup tools.
10_PostRepair_Installers   Customer-approved installers after repair.
11_Utilities               7-Zip, editors, viewers, hashing tools.

Do not store customer data in Tools. Customer files belong under Reports\Tickets.
