Start here:

1. Double-click START_HERE.cmd.
2. Use the colorful RescueDesk command center.
3. Click "Open Service Console" for the powerful technician menu.

Simple folder map:

- Command_Center: GUI launcher, PowerShell service console, and WinPE command center.
- Tools: downloaded repair utilities, grouped by job.
- Docs: workflow guides, checklists, boot notes, malware flow, and post-repair flow.
- Reports: ticket folders, exports, screenshots, closeout packages, and hashes.
- Admin: official download manifest, dashboard, and build maintenance files.
- Boot: WinPE automation and Ventoy ISO staging.
- assets: GitHub screenshots and branding assets.

One rule:

Use START_HERE.cmd first. Do not hunt through folders during a service job.
