# Download These Files

Use `Admin\Manifests\Tool_Manifest.csv` for official URLs, placement folders, license notes, and risk levels.

## Must-Have Boot Tools

- Ventoy: `Tools\01_Boot_Recovery_ISOs`
- Windows 11 installation media: `Boot\Ventoy_ISOs`
- R2K WinPE Command Center ISO: `Boot\Ventoy_ISOs`
- Rescuezilla ISO: `Boot\Ventoy_ISOs`
- Memtest86+ ISO/image: `Boot\Ventoy_ISOs`

## Must-Have Repair Tools

- Sysinternals Suite: `Tools\05_Windows_Repair`
- Microsoft Safety Scanner: `Tools\04_Malware_Cleanup`
- Malwarebytes AdwCleaner: `Tools\04_Malware_Cleanup`
- TestDisk and PhotoRec: `Tools\03_Backup_Data_Recovery`
- CrystalDiskInfo: `Tools\02_Diagnostics_Hardware`
- HWiNFO: `Tools\02_Diagnostics_Hardware`
- Snappy Driver Installer Origin: `Tools\07_Drivers_Firmware`

## After Downloading

1. Put each file in the matching folder.
2. Run the service console.
3. Use "Check missing tools / open download dashboard".
4. Generate a hash manifest.
5. Zip the finished build.
