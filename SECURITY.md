# Security

R2K RescueDesk USB is intended for authorized repair work only.

## Do Not Report

Please do not submit customer data, passwords, BitLocker recovery keys, malware samples, or private ticket logs.

## Responsible Use

- Get customer approval before repair actions.
- Back up data before risky changes.
- Keep customer reports out of Git.
- Download third-party tools from official sources.
- Check commercial-use license terms.

## Contact

Use GitHub issues for non-sensitive project feedback.
