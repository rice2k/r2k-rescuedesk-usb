# Account Recovery Policy

## Approved Goal

Help the authorized customer regain access without bypassing Windows security or encryption.

## Approved Paths

- Microsoft account password reset.
- Windows sign-in "I forgot my password" flow.
- Local account security questions.
- Previously created local password reset disk.
- Work/school self-service password reset.
- Organization admin reset for managed devices.
- BitLocker recovery key lookup.
- Data backup, then Reset this PC or reinstall with customer approval.

## Not Allowed

- Password cracking.
- SAM editing.
- Account bypass.
- Encryption bypass.
- Tools advertised as unlocking any Windows laptop.

## Technician Script

"We can help recover access through Microsoft-supported recovery options. If those do not work, we can help protect your data where possible and reset or reinstall Windows with your approval. If BitLocker is enabled, we need your recovery key before accessing the drive offline."
