# Post-Repair Checklist

## Core Checks

- Confirm original issue is resolved.
- Reboot at least once.
- Check Windows activation.
- Run Windows Update.
- Check Device Manager.
- Confirm network works.
- Confirm customer files are present or backup location is documented.
- Confirm BitLocker state if changed during service.

## Drivers And Firmware

- Use OEM updater for Dell, HP, or Lenovo when appropriate.
- Use Intel DSA for Intel Wi-Fi/Bluetooth/graphics when appropriate.
- Use AC power for firmware updates.
- Do not interrupt BIOS/firmware updates.

## Customer Apps

- Install only customer-approved apps.
- Use Ninite for common apps when appropriate.
- Avoid bundled installers and random mirrors.

## Handoff

- Create customer report.
- Save screenshots/logs under the ticket folder.
- Close ticket in RescueDesk console.
- Explain recommended next steps.
