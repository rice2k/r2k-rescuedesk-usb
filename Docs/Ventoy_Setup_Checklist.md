# Ventoy Setup Checklist

1. Insert the service USB.
2. Back up anything on the USB.
3. Open Ventoy from the official download.
4. Confirm the correct USB device.
5. Install Ventoy to the USB.
6. Copy boot ISOs into `Boot\Ventoy_ISOs`.
7. Copy the `R2K_RescueDesk_USB` folder to the USB data partition.
8. Boot test on at least one UEFI/Secure Boot system.
9. Record the Ventoy version in the manifest notes.

Do not install Ventoy to a customer drive.
