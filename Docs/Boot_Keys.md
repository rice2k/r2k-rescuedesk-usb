# Common Boot Menu Keys

- Dell: F12
- HP: Esc, then F9
- Lenovo: F12 or Novo button
- ASUS: Esc or F8
- Acer: F12, sometimes enabled in firmware first
- MSI: F11
- Samsung: Esc or F10
- Microsoft Surface: hold Volume Down while pressing Power

Use the one-time boot menu when possible. Avoid permanent firmware changes unless needed, and document any firmware setting you change.
