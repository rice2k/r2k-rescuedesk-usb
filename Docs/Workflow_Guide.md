# R2K Service Workflow

## Easy Bench Flow

1. Start with `START_HERE.cmd`.
2. Set the ticket number.
3. Run Quick Triage Report.
4. Check drive health before repairs.
5. Back up user data if there is any risk.
6. Run the correct repair path.
7. Create the customer handoff report.
8. Save screenshots, logs, and notes under `Reports\Tickets\<TicketNumber>`.

## Stop And Ask Before Continuing

Stop and get customer approval if:

- Drive health is caution, bad, or unknown and data matters.
- BitLocker key is required.
- The job may require reset, reinstall, boot repair, partition work, or account recovery.
- The PC appears work/school managed.
- Ownership or authorization is unclear.

## Folder Rules

- Put downloaded tools only under `Tools`.
- Put ticket work only under `Reports\Tickets`.
- Put build notes and manifests only under `Admin`.
- Put general instructions only under `Docs`.
- Do not create random folders at the USB root.
